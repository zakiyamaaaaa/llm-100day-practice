# LLM Studio — 100日学習ラボ

既存カリキュラムと学習記録を読む、静的HTMLの学習サイトです。

- Day31〜100の70レッスン、32件の学習ノートを収録。Day1〜30は元資料にある概要のみです。
- 過去の確認問題を再構成した33問を1問ずつ出題し、採点・解説・再挑戦を提供します。
- RRF、引用評価、Agentの予算、非同期処理を4つのラボで実験できます。
- 振り返りはMarkdown、復習記録はJSONで書き出せます。
- サイトの操作はLLM APIを呼びません。

## 起動

リポジトリのルートで `python3 -m http.server 8765 --bind 127.0.0.1 --directory learning-site` を実行し、ブラウザで `http://127.0.0.1:8765` を開きます。

## データ更新と配布

リポジトリのルートで `python3 learning-site/build.py` を実行すると、カリキュラム・進捗表・日別ノートからdata.jsと配布用distを再生成します。元資料がない配布先では `python3 build.py --package-only` で同梱data.jsを使用できます。

`node verify.cjs` は学習データ、クイズ、各ラボの計算、採点と保存をネットワークなしで検証します。

## 保存範囲

復習と振り返りはlocalStorageに保存され、元のprogress.md・notes・memo.mdを変更しません。ブラウザ・端末・URLごとに保存先が異なり、自動同期はありません。ブラウザデータ削除前にエクスポートしてください。

未着手Dayに詳細ノートがない場合、到達点のみを表示します。学習済みとサイトでの復習は別管理です。引用評価は文書ID照合の模型であり、本文の意味的な根拠性を判定するものではありません。
