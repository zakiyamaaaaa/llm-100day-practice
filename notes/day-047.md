# Day 47: Generation評価と引用の正確性

## 学習テーマ

RAG回答に含まれる引用を抽出し、引用の根拠性・Precision・Recall・正確性を評価した。

## 学習した内容

- 引用の根拠性は、引用文書がcontextに存在するかを確認する。
- Citation Precisionは、引用した文書のうち正解文書が占める割合。
- Citation Recallは、引用すべき正解文書のうち実際に引用できた割合。
- Citation Recallは余計な引用を直接減点しないため、Recallが1.0でも引用が不正確な場合がある。
- 余計な引用を検出するにはPrecisionも確認する必要がある。
- 未回答ケースでは、引用がないことを正解とする。
- 引用の正確性では、実際の引用集合と期待する正解文書集合を比較する。

## 実行結果

| ケース | 引用正確性 | Precision | Recall |
|---|:---:|---:|---:|
| correct_citation | True | 1.00 | 1.00 |
| missing_citation | False | 0.00 | 0.00 |
| wrong_citation | False | 0.00 | 0.00 |
| extra_citation | False | 0.50 | 1.00 |
| unknown_without_citation | True | — | — |
| unknown_with_citation | False | — | — |

集計:

- 引用正解率: 2/6 (33.33%)
- 引用根拠性: 5/6 (83.33%)

## 発生した問題と修正

`extra_citation`で、正解文書に加えて余計な文書を引用していたにもかかわらず、引用正確性がTrueになった。

原因は、正解文書との共通部分だけを比較していたため。実際の引用集合全体と正解文書集合を比較するように修正した。

```python
is_citation_correct = (
    is_citation_supported
    and cited_document_ids == relevant_document_ids
)
```

## 確認問題と回答

初回3問:

1. `missing_citation`のPrecisionとRecallが0になる理由: 引用がないため。正解。
2. `extra_citation`のRecallが1.0で正確性がFalseの理由: 未回答。解説後に理解。
3. `wrong_citation`の根拠性がFalseの理由: 間違った引用。部分正解。正解文書ではなくcontextにも存在しない点を補足。

追加問題:

1. 期待`{doc_2}`、実際`{doc_1, doc_2}`の指標: Recall 1.0、Precision 0.0と回答。Precisionは0.5であることを解説。
2. `wrong_citation`が不適切な理由: 正解文書ではなく、contextにも存在しない。正解。
3. 期待`{doc_2}`、実際`{doc_2}`の指標: Precision 1.0、Recall 1.0。正解。

## 要復習

- Precisionは「引用したものの正しさ」、Recallは「必要な引用を取りこぼしていないか」。
- 引用集合の完全一致と、Precision/Recallの違い。
- 引用の根拠性と、引用の正確性の違い。
